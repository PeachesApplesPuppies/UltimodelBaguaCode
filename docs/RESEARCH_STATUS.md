# Research status and interpretation boundaries

Ultimodel’ Calculator / Grapher is an experimental software and mathematical-modeling project.

The codebase deliberately separates established mathematics from BCE-specific interface vocabulary and from speculative interpretation.

## Implemented / computational

Examples include:

- real scalar expression parsing and evaluation;
- derivatives and bounded numerical integration;
- Lens-oriented delta, magnitude, ratios, and promotion;
- three-bit state tokens and XOR transitions;
- Hamming distance and changed:unchanged ratios;
- Recognition Events, Rhyme Candidates, stress tests, append-only provenance, and exports;
- saved periodic-table data used as ordinary numerical inputs.

## Experimental vocabulary

Examples include:

- Eternal Variable’ (§);
- Eternal Function (◯);
- Eternal Polarity (❂ / ⊛);
- Lens’;
- Flow’;
- Rhyme;
- Periodic Mycelium.

These names are project vocabulary, not claims of established scientific terminology.

## Hypotheses

Cross-domain relationships, universal interpretations, recurrence claims, and proposed physical or psychological mappings should be treated as hypotheses until separately defined and tested.

The Recognition / Resonance engine is intended to preserve both successful and failed candidate relationships. A recorded recognition is data about an observation; it is not automatically evidence that the perceived relationship is objectively real.
