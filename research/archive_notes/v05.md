# BCE Certified Boundary Engine v0.5
Python 3.10+, `python -m pip install -r requirements.txt`, then `python engine.py`. Default checkpoint.json is created separately from bundled results.json. Ctrl+C interrupts; each completed stage is committed via fsync and atomic replace. Do not use concurrent writers. Delete checkpoint.json or choose --output another.json to rerun. A forced stop can lose current stage only; filesystem durability is platform-dependent.

## Method and proof obligations
Uses mpmath.iv 35-digit rectangular intervals and a custom Euler–Maclaurin zeta enclosure, N=24, M=12; Bernoulli numbers calculated exactly as fractions. No call to mpmath's noninterval zeta. The remainder after M corrections is bounded by |(s)_(2M)| |B_(2M)|/(2M)! N^(1-sigma-2M)/(sigma+2M-1), sigma a lower bound on Re(s). This follows from the periodic Bernoulli bound and integrating x^(-sigma-2M). See https://dlmf.nist.gov/25.2 and https://dlmf.nist.gov/25.11. For 0<=Re(s)<=1, 10<=Im(s)<=33, |s+j|<=34+j, giving an exact uniform truncation bound 434190011914636475855/852108968543237079509135385427968 < 5.10e-13. Interval evaluation adds arithmetic and range uncertainty separately. Each coordinate is inflated by the remainder bound.

Each entire boundary segment is mapped into a rectangular enclosure, rotated by 1+i/3. If a real or imaginary coordinate has strict sign, the segment avoids zero and its image can be homotoped to the chord in that half-plane. Endpoint signs and a strict real sign (when required) certify signed positive-ray crossings of the chord. A sum of crossings is the winding number; no phase sampling or explicit pi evaluation is used for counting. The zeta pole must be outside the rectangle. Uncertain edges are bisected; after depth cap, the region is subdivided with alternative rational cuts. A parent count is accepted only if all children certify. A genuine boundary zero cannot be silently skipped. Bounds on the rotated modulus are not bounds on zeta without dividing by |1+i/3|.

## Results and caveat
All four previous v0.4 high-resolution counts reproduced. Five disjoint symmetric rectangles each count one zero; symmetry rho -> 1-conjugate(rho) plus uniqueness implies exact critical-line location, conditional on interval implementation correctness. Counts include multiplicity. 16 quartic regressions, repeated root, boundary-root rejection, and subdivision recovery passed. The backend mpmath.iv is experimental; these are mathematically bounded interval computations, not independently audited formal certificates. python-flint/Arb was unavailable in this runtime; independent Arb replication is recommended. See https://mpmath.org/doc/current/contexts.html.

Prior v0.2 pi normalization identity and symmetry counterexample remain unchanged. v0.3 polynomial threshold and v0.4 rational model counts agree with new regressions. Earlier prime reconstruction and heat-kernel calculations are not certified by this engine; they were not rerun here. No proof of RH or bound on Newman constant follows from finite undeformed zeta counts. Prior input hashes in results.json record the sources inspected.
