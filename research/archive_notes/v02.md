# BCE Centerpoint Laboratory v0.2
Run `python -m pip install numpy mpmath`, then `python lab.py`. Results are written to results.json after computations. Ctrl+C interrupts; no input files are modified. Numerical experiments, not a proof of RH.

## Proof-obligation ledger
1. Exact: xi(s)=xi(1-s); F(t)=xi(1/2+it) is even and real on the real axis.
2. Exact: RH is equivalent to F having only real zeros.
3. Counterexample: even real polynomials can have nonreal zeros in symmetric quartets. Positive coefficients alone are insufficient in the squared centered coordinate.
4. Necessary under RH: Laguerre inequality F'^2-F F'' >= 0 on the real axis. Sampling is not certification.
5. Equivalent infinite criterion: all Jensen polynomials of the Taylor coefficient sequence of G(u)=xi(1/2+sqrt(u)) are hyperbolic (real-rooted). The program uses approximate contour quadrature and floating-point roots; finite passes are not proof. A finite Taylor prefix cannot force global confinement.
6. Pi experiment: replacing pi by a>0 multiplies xi by (pi/a)^(s/2), which never vanishes. Thus zeros are unchanged. Reflection symmetry in this family singles out a=pi (for all s), not because zeros move but because normalization changes.
7. Open: prove the infinite criterion or find a certified violation. Do not infer a global conclusion from sampled data.
