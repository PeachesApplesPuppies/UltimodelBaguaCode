# BCE v1.3 Multiscale Cancellation Engine
Run `python -m pip install numpy` and `python engine.py`. Ctrl+C interrupts; the final JSON is written atomically. A rerun recomputes all stages; no input is modified. Requires memory for arrays up to ten million entries. Results are numerical, not interval certified. The five endpoint reference values come from the archived v0.1 riemann_results.txt; the Mellin identity comes from v1.2.

E(x)=psi(x)-x, F(t)=exp(-t/2) E(exp(t)). A term x^rho/rho in the explicit formula has normalized envelope exp((Re rho-1/2)t)/|rho|. The FFT uses a Hann window and uniform log samples without supplying zero ordinates. Peaks are approximate; resolution is 2*pi/log(100000). Synthetic tests are individual oscillatory signals, not modified zeta functions.

Weighted energy I(eps)=integral_1^infinity E(x)^2 x^(-2-2eps) dx = integral_0^infinity |F(t)|^2 exp(-2eps*t) dt. RH implies I(eps)<infinity for every eps>0 via the standard prime discrepancy bound E(x)=O_eta(x^(1/2+eta)), choosing eta<eps. Conversely, if every I(eps) is finite, Cauchy-Schwarz bounds the absolute Mellin integral by sqrt(I(eps))*[2(Re s-1/2-eps)]^(-1/2) for Re s>1/2+eps. On compact subsets choose eps smaller than the minimum gap; dominated integration yields holomorphy. The identity Z'/Z=1-s*integral E(x)x^(-s-1) dx initially holds for Re s>1, Z=(s-1)zeta(s). Meromorphic identity continuation excludes poles (zeros of Z) in Re s>1/2; reflection then gives RH. No new proof of the required energy bound is supplied. The discrete logarithmic shell energy criterion W_j=integral_(10^j)^(10^(j+1)) E(x)^2/x^2 dx, W_j=O_eps(10^(eps*j)) for every eps>0, is equivalent to that integrability by comparison on each shell. A uniform bound would be sufficient but is not established or required by RH here.

The engine uses two-point Gauss quadrature on integer cells, with floating arithmetic and no explicit quadrature enclosure. The synthetic RMS values use trapezoidal integration. Finite shell behavior cannot bound the infinite tail. No RH proof is claimed.
