# BCE Zero Boundary Engine v0.4
Python 3.10+. Install: `python -m pip install -r requirements.txt`. Run: `python engine.py`. Ctrl+C stops the current stage; completed stages are atomically committed and resumed on restart. `--fresh` resets the selected checkpoint; `--stage models` or `--stage xi` restricts execution. Do not run concurrent writers. A forced kill can lose the current stage, not normally the prior atomic checkpoint. No input files are modified.

## Proof ledger
Polynomial certificates: for a rational complex segment [a,b], bound |p'| by sum k|c_k|R^(k-1), with R=max(||a||_1,||b||_1). Multiply by ||b-a||_1. If this is strictly below max(|Re p(a)|,|Im p(a)|), both the image curve and its chord are in a disk excluding zero. Homotopy preserves winding; exact rational signed ray crossings give the argument-principle count. Adaptive bisection rejects uncertifiable boundaries. Counts include multiplicities. Exact for valid nondegenerate rectangles and nonzero polynomial. Bundled quartic tests use ascending coefficients [1+12t²,0,-12t,0,1].

Zeta counts: numerical phase increments at 64 and 128 samples per edge, 25 and 40 decimal digits. Agreement is NOT a certificate: unresolved phase wrapping or numerical evaluation error may conceal zeros. Rectangles avoid the pole and trivial zeros, so zeta and completed xi have identical zero counts there. A thin band is not the critical line. No deformed Xi quadrature certification, no Newman constant bound, no RH proof. Next step is validated complex interval arithmetic for zeta or the deformed kernel, including derivative and tail bounds.

Pi: the factor 2pi normalizes winding angle to full turns. Exact polynomial counting instead uses signed ray crossings and never evaluates pi.
