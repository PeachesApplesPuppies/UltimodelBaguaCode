# BCE v0.7 — invariant partition experiment
Run `python -m pip install mpmath` and `python tiling.py`. Ctrl+C interrupts; results.json atomically stores each completed case. Remove results.json to rerun all cases. No known zeta ordinates are used. The inherited v0.5 mpmath.iv backend is experimental, not independently audited.

For functions whose zeros are invariant under s -> 1-conjugate(s), a reflection-invariant rectangle with total multiplicity one contains a simple critical-line zero. This premise is required; it is not automatically verified for arbitrary functions passed to tiling(). Counts are additive if all boundaries exclude zeros. Horizontal subdivision conserves reflection invariance. A bounded rectangle with simple, distinct-height, critical-line zeros admits a finite such partition, assuming zero-free boundaries; the finite depth/precision implementation need not find it. Off-line reflection pairs have the same height and cannot be separated by horizontal cuts. A repeated critical-line zero likewise cannot be reduced to a multiplicity-one region. Thus symmetry and subdivision do not prove RH, and universal singleton termination is stronger than RH. A failed count or exhausted depth is unresolved, never evidence of an off-line zero by itself.
