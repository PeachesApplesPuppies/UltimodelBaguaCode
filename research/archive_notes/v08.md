# BCE Bidirectional Engine v0.8
Run `python -m pip install mpmath` then `python engine.py` in this directory. Ctrl+C interrupts; completed cases are saved atomically in results.json. Delete results.json to rerun all cases.

Uses v0.7 Euler–Maclaurin interval boundary counter (mpmath.iv, experimental; independent Arb audit still needed). Vertical symmetric three-way cuts can isolate off-line pairs, horizontal cuts separate heights. Counts on all children must sum to the parent count when available. Exact rational geometry audits coverage and disjoint interiors. A symmetric rectangle with multiplicity one forces its zero onto the critical line, provided the supplied function has reflection-symmetric zeros. All supplied controls have that property. Do not apply this classification to arbitrary functions without establishing symmetry.

Repeated zeros remain unresolved by design: a count of two does not identify two distinct locations. A narrow central rectangle is not evidence of exact confinement. This version does not implement general multiplicity certification. The polynomial repeated control is (s²−s+17/4)², which has a double zero at 1/2+2i and its conjugate. The off-line control has zeros at 1/4±2i and 3/4±2i. The simple control has zeros at 1/2±i and 1/2±2i. v07_reference.json retains earlier results for comparison. No global RH proof or termination claim.
