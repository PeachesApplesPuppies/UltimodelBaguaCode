# BCE Uniqueness Engine v0.6
Run `python -m pip install -r requirements.txt` then `python engine.py`. Ctrl+C stops execution; each completed test is atomically saved to checkpoint.json. Resume with the same command. Use --output with a new filename to rerun. Do not run concurrent writers. Bundled results.json and run.log are from the actual test run. boundary.py is the prior v0.5 engine, retained for regression and reuse.

## Proof criterion
If f is holomorphic on a convex region D and a fixed complex c satisfies Re(c f'(z)) > 0 throughout D, integrate the derivative along the straight segment from z1 to z2. The real part of c(f(z2)-f(z1))/(z2-z1) is positive, so distinct points cannot have the same image. This proves injectivity and at most one zero. A boundary count of one proves existence and simplicity. For zeta in a symmetric rectangle in the critical strip, reflection rho -> 1-conjugate(rho) then forces Re(rho)=1/2. This is a sufficient local criterion, not necessary and not a proof of RH. In particular a function containing multiple zeros cannot be globally injective on a region containing them.

## Derivative bound
Differentiate the finite Euler-Maclaurin sum using the product rule. The analytic remainder R is holomorphic in Re(s)>1-2M (the pole terms cancel). For each s use Cauchy's derivative estimate on a circle of radius h=1/8, enclosed by the expanded rectangular interval. Bound |R| there by the v0.5 periodic Bernoulli remainder formula and divide by h. Inflate both coordinates of the derivative by that upper bound. The fixed rotation is selected from the midpoint derivative, but its positivity is checked over the full region, recursively subdividing with rational cuts if necessary. The derivative test and winding count share the EM backend, so are not independent arithmetic implementations. Arithmetic is mpmath.iv, experimental, not formally audited. Arb was unavailable and installation failed because network access was unavailable.

## Results and limitations
Five small rectangles passed both tests; four artificial controls behaved as expected. The off-axis pair control represents f(z)=z^2+1, derivative 2z, on a rectangle containing both roots. The wide rectangle spanning heights 10 to 33 did not pass the injectivity criterion, as expected because it contains multiple zeros. No global covering or completeness proof is asserted. Earlier v0.5 total count of five was not rerun here; see v0.5 source for its methodology. No new bound on the Newman constant. The pi normalization identity remains unchanged; no explicit pi evaluation is required by this crossing or derivative criterion, though zeta itself has connections to pi. A global proof would need to establish existence/uniqueness or exclusion for an exhaustive cover at unbounded heights, not merely near numerically known zeros.
