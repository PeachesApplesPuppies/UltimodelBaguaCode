Run `python -m pip install numpy` then `python engine.py`. Ctrl+C interrupts; the final results file is atomically replaced. Reruns recompute. No input modified. Numerical quadrature is not interval-certified. Prior v1.3 results included for regression.

Let h=log 2, F(t)=exp(-t/2)(psi(exp(t))-exp(t)), W_j=integral_{jh}^{(j+1)h}|F|^2 dt. For epsilon>0 the weighted energy is between sum_j exp(-2 epsilon (j+1)h) W_j and sum_j exp(-2 epsilon jh) W_j. Thus RH iff limsup W_j^(1/j)<=1 (by v1.3 Mellin argument and standard RH prime error bound). Sufficient recurrence: W_{j+1} <= (1+a_j)W_j+b_j with nonnegative a_j,b_j, sum_{k<j}log(1+a_k)=o(j), and log(1+sum_{k<j}b_k)=o(j). Iteration gives W_j <= (W_0+sum b_k) product(1+a_k). No unconditional proof of these assumptions for primes is supplied. Strict monotonicity fails numerically. Finite data cannot force asymptotic recurrence: the analytic signal cos(20t)+exp(delta(t-T0))*cos(23t) is arbitrarily close on a finite prefix but grows exponentially, with positive exponential energy rate. This synthetic signal is not a prime discrepancy function or a zeta counterexample.
